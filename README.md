# 🛡️ AgentHive-AI: The Multi-Tasking Decision Agent

AgentHive-AI is an autonomous reasoning agent built for an MLH Hackathon. It helps navigate complex strategic decisions by combining real-time web research, simulated pro/con debates, and tactical roadmap generation.

### 🚀 Key Features
* **Live Research:** Uses DuckDuckGo to scrape current market data and trends.
* **Agentic Debate:** Simulates a conflict between "The Optimist" and "The Risk Auditor" to prevent bias.
* **Tactical Roadmap:** Consolidates analysis into a 30-day execution plan.

### 🛠️ Tech Stack
* **Language:** Python 3.12+
* **Intelligence:** Google Gemini 1.5 Flash (via Gemini API)
* **Interface:** Streamlit
* **Tools:** DDGS (DuckDuckGo Search)

### 💻 Setup & Installation
1. Clone the repo: `git clone https://github.com/Adrija-dotcom/AgentHive-AI.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `streamlit run app.py`

### 🧠 Project Vision
Developed as a tool for cybersecurity startups and strategic pivots, AgentHive-AI aims to eliminate decision paralysis by providing grounded, multi-perspective AI reasoning.
